# 🌱 EcoSync AI

### Intelligent Workspace & Energy Optimizer

**EcoSync AI** is an AI-powered workspace optimization concept designed to help users understand their computer's resource usage, identify inefficient workloads, and receive intelligent recommendations for improving performance and energy efficiency.

The project is designed with a focus on **Snapdragon-powered PCs and on-device AI** as the target environment.

---

## 🎯 Problem

Modern computers often run multiple applications and background processes simultaneously.

This can lead to:

* 🔋 Higher battery consumption
* 💻 Unnecessary CPU and RAM usage
* ⚡ Reduced system efficiency
* 🌱 Increased energy consumption
* 📊 Difficulty understanding which workloads affect performance

Users need a simple way to understand their workspace and make better usage decisions.

---

## 💡 Our Solution

EcoSync AI analyzes workspace and resource-usage data and provides intelligent recommendations.

### Core Flow

**Monitor → Analyze → Understand → Recommend → Optimize → Save Energy**

---

## 🚀 Features

### 📊 Smart Dashboard

Displays:

* Battery level
* CPU usage
* RAM usage
* Active applications
* Estimated energy consumption
* Estimated energy savings
* Workspace efficiency score

### 🤖 AI Workspace Analysis

The application analyzes workspace data and identifies:

* High-resource applications
* Low-use applications
* Background workloads
* Battery-impacting applications
* Overall workspace efficiency

### 💡 Smart Recommendations

EcoSync AI provides actionable suggestions such as:

* Closing unused applications
* Reducing unnecessary background workloads
* Managing resource-heavy applications
* Switching to an appropriate workspace profile

### 🔋 Energy Insights

Interactive visualizations show:

* CPU usage trends
* Memory usage trends
* Estimated energy consumption
* Estimated energy savings

### 🧑‍💻 Workspace Profiles

Users can select different profiles:

* 📚 Study
* 💻 Coding
* 🎤 Meeting
* ⚡ Performance
* 🔋 Battery Saver

### 🌱 Eco Score

EcoSync AI provides a **0–100 workspace efficiency score** based on the available usage data.

### 💬 AI Assistant

The built-in assistant provides guidance for questions related to:

* Battery usage
* CPU/RAM consumption
* Workspace efficiency
* Battery-saving practices

### 🧪 Demo Mode

Demo Mode provides simulated PC metrics so the complete application can be demonstrated even when real Windows hardware metrics are not available.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Tanmai-13/ecosync-ai.git
```

### 2. Navigate to the project

```bash
cd ecosync-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local development URL shown in the terminal.

## 🧪 Current Prototype

The current prototype uses **simulated resource and energy data** for demonstration purposes.

It does **not** directly terminate applications, modify operating-system settings, or claim access to real hardware sensors.

Future versions can integrate real system metrics and hardware-specific AI capabilities.
